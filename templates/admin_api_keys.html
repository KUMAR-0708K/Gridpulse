GridPulse REST API Integration Guide
v1.2 REST
Authentication Protocol

All requests to protected /api/* endpoints must include a valid active API key. You can authenticate using any of the following methods:

Standard Header (Recommended)
X-API-Key: <your_key>
Standard custom HTTP header for API gateways.
Bearer Authorization
Authorization: Bearer <your_key>
Compatible with standard OAuth2 / JWT client libraries.
Query Parameter
?api_key=<your_key>
Convenient for quick testing in web browsers or WebHooks.
curl -X GET http://127.0.0.1:5000/api/auth/verify \
  -H "X-API-Key: {{ master_api_key }}"
curl -X GET "http://127.0.0.1:5000/api/outages?status=active" \
  -H "X-API-Key: {{ master_api_key }}"
curl -X POST http://127.0.0.1:5000/api/outages \
  -H "X-API-Key: {{ master_api_key }}" \
  -H "Content-Type: application/json" \
  -d '{
    "locality_id": 1,
    "consumer_name": "SCADA Substation Feeder 4A",
    "consumer_phone": "+91 94481 00912",
    "address": "12th Cross, Sector 2",
    "landmark": "Near Feeder Busbar 3",
    "outage_type": "Distribution Transformer Failure",
    "severity": "CRITICAL",
    "description": "Overcurrent telemetry breaker trip detected.",
    "affected_households": 120
  }'
import requests

API_KEY = "{{ master_api_key }}"
BASE_URL = "http://127.0.0.1:5000"

headers = {
    "X-API-Key": API_KEY,
    "Content-Type": "application/json"
}

# 1. Fetch Outages
response = requests.get(f"{BASE_URL}/api/outages", headers=headers)
print("Outages:", response.json())

# 2. Ingest Grid Fault Telemetry
payload = {
    "locality_id": 1,
    "outage_type": "Distribution Transformer Failure",
    "severity": "CRITICAL",
    "description": "Automatic sensor telemetry trip.",
    "affected_households": 95
}
post_resp = requests.post(f"{BASE_URL}/api/outages", json=payload, headers=headers)
print("Ticket Created:", post_resp.json())
const API_KEY = "{{ master_api_key }}";

// Fetch active outages with API Key Header
fetch("http://127.0.0.1:5000/api/outages?status=active", {
    headers: {
        "X-API-Key": API_KEY,
        "Content-Type": "application/json"
    }
})
.then(res => res.json())
.then(data => console.log("GridPulse Outages:", data))
.catch(err => console.error("Error:", err));
